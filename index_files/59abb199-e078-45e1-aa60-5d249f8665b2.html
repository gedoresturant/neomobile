# ONETOUCH - طريقة التحميل والتشغيل

## الملفات:
1. ONETOUCH-FINAL-DOWNLOAD.html - النسخة الكاملة الخفيفة (أنصحك بيها)
   - تشتغل أوفلاين 100%
   - طباعة مباشرة بدون صفحات محظورة
   - محاسبة كاملة للادمن
   - مسح الصيانة للادمن

2. ONETOUCH-REACT-FINAL.html - نسخة React المتقدمة

## طريقة التحميل:
1. دوس على رابط التحميل
2. الملف هينزل في مجلد Downloads
3. افتحه في جوجل كروم

## التشغيل على الموبايل:
1. انقل الملف للموبايل (واتساب لنفسك أو جوجل درايف)
2. افتحه في كروم
3. دوس 3 نقط > Add to Home Screen > إضافة للشاشة الرئيسية
4. هيبقى أيقونة زي التطبيق

## اليوزرات:
- admin / admin123 - مدير عام (كل الصلاحيات)
- store / store123 - مخزن
- sales / sales123 - مبيعات
- maint / maint123 - صيانة

## الطباعة:
- دوس اطبع الآن -> هتظهر قائمة الطابعات + حفظ PDF
- لو عندك طابعة حرارية: نزل RawBT من متجر بلاي
